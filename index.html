🎯 1. Why SomnoSync Was Built (The Motivation)

The Problem

Bedtime phone usage has become an ingrained societal habit. Algorithms engineered for infinite engagement (TikTok, Reels, YouTube) combined with high screen brightness delay nocturnal melatonin secretion, lengthening sleep latency and inducing cumulative sleep debt.

  • ▸ Physiological Suppression: Blue light and cognitive arousal delay the circadian sleep gate.
  • ▸ Quantification Gap: Users lack visibility into how 45 extra phone minutes translates into real sleep delay ($r = +0.86$) and morning fatigue ($r = +0.71$).
  • ▸ Core Objective: Provide automated machine learning inference to estimate exact onset delay and actionable behavioral counterfactuals.

⚙️ 2. How It Was Built (The Machine Learning Pipeline)

Architecture

Trained on Kaggle's verified 8,500-participant bedtime dataset with 0 null values. Preprocessed via `ColumnTransformer` (StandardScaler for continuous variables, OneHotEncoder for categorical features) using stratified 80/20 train-test splits.

  • ▸ Model 1 (Classifier): Random Forest multi-class predictor for 4 sleep debt tiers (96.88% Accuracy, 0.935 Macro F1).
  • ▸ Model 2 (Latency Regressor): Random Forest predicting onset delay in minutes (R² = 0.846, MAE = 5.58 min).
  • ▸ Model 3 (Fatigue Regressor): Gradient Boosting model predicting next-day fatigue on a 1–10 scale (R² = 0.943, MAE = 0.48).
